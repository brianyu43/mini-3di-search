# 채점 규칙의 근거와 검증 범위

현재 숫자는 생물학적 최적화를 거친 설정이 아니다. 먼저 **정해진 점수 규칙에 대해
최적 정렬을 정확히 계산하는지** 확인하기 위한 합성 설정이다.

| 설정 | 실제 값 | 근거와 범위 |
|---|---|---|
| M1/M2 데모 일치/불일치 | +5 / -4 | 프로젝트가 만든 단순 정수 fixture. 일치 보상과 불일치 비용의 계산을 확인하기 쉽다. 이 특정 숫자가 최적이라는 실험 근거는 없음 |
| unknown X | 어느 문자와 비교해도 0 | 합성 입력의 중립 정책. X=X도 보상을 주지 않음. 길이/위치는 유지하고 seed에는 사용하지 않음. 실제 exporter/matrix의 정책은 M3에서 확인 |
| 데모 gap 시작/연장 | 10 / 1 | RESEARCH_PLAN 7.2의 교육용 기본값. Foldseek의 공식 최적 설정이라고 주장하지 않음 |
| 손계산 테스트 | +6 / -20, gap 3 / 1 | 특정 gap 경로와 재채점 오류를 분명하게 시험하기 위한 별도 fixture |
| M2 ungapped threshold | 데모에서 20 | 실행 전에 정한 설명용 값. 데이터로 튜닝하거나 생물학적 적합성을 확인한 값이 아님 |

gap은 처음 열 때 한 번 비용을 내고, 길어질 때마다 연장 비용을 낸다.
`gap_cost(l) = open + (l-1)*extend`이므로 기본값으로 길이 1은 10, 길이 3은 12다.
한 덩어리의 긴 빈칸을 같은 총 길이의 여러 독립 빈칸보다 덜 벌점 주는 구조다.
이런 affine gap 형식은 표준 정렬 모델이며
[Biopython 공식 문서](https://biopython.org/docs/latest/Tutorial/chapter_pairwise.html#affine-gap-scores)도
시작/연장 비용을 구분한다. 이 형식의 근거와 10/1이라는 특정 수치의 타당성은 별개다.

손계산 fixture의 `AACCAA`와 `AA--AA`에서는 일치 네 개가 `4*6=24`,
길이 2 빈칸이 `3+1=4`이므로 20점이다. 큰 mismatch 비용 -20은 해당 입력에서
빈칸을 쓰는 경로를 명확히 시험하게 한다. 데모와 테스트 숫자가 달라도 각 비교에서는
엔진과 oracle에 반드시 동일한 설정을 준다. 빈칸 비용은 여섯 조합으로도 검사한다.

## 검증기가 같은 규칙을 사용하는 이유

정렬 엔진은 모든 허용 정렬 중 가장 높은 점수와 그 경로를 찾는다.
Biopython oracle은 동일한 문제를 별도 라이브러리로 풀어 최댓값을 비교한다.
독립 재채점기는 엔진이 내놓은 경로를 읽으며 점수와 좌표 소비량을 다시 검사한다.
아주 짧은 입력에는 모든 정렬 경로를 직접 열거하는 추가 검사도 있다.

같은 채점표를 공유하는 것은 같은 수학 문제를 비교하려는 조건이다.
독립적인 부분은 **답을 구하는 구현**이다. 재채점만으로는 최적성을 확인할 수 없으므로
Biopython 및 작은 입력의 경로 전수 열거로 최고 점수도 확인한다.
같은 점수의 최적 경로가 여럿이면 Biopython과 좌표를 강제로 같게 맞추지 않는다.

따라서 통과의 의미는 “이 규칙을 정확히 계산한다”이다. “이 점수가 실제 구조 관련성을
잘 반영한다”는 판단에는 추가 근거가 필요하다. M3에서 출처/버전/hash를 고정한 실제
3Di 행렬을 도입하고, 이후 독립 SCOPe label을 이용한 평가로 검색 품질을 확인한다.
행렬을 바꿔도 독립 정렬 검증은 다시 필요하다. 자체 raw score에 E-value, TM-score,
상동성 확률의 의미를 붙이지 않는다.
